# 3DCG Portfolio — GitHub Pages

このフォルダは、無料の GitHub Pages で公開できるポートフォリオサイトのテンプレートです。

## 1. まず変更する場所

### index.html
- `YOUR NAME` → 自分の名前
- `YOUR_EMAIL@example.com` → メールアドレス

### profile.html
- 名前
- 自己紹介
- 使用ソフト
- 担当範囲

### works/character.html
キャラクター画像を `assets/character.jpg` として追加し、プレースホルダー部分を `<img>` に変更。

### works/animation.html
YouTube動画URLが例えば
`https://www.youtube.com/watch?v=AbCdEf12345`
なら、

`https://www.youtube.com/embed/AbCdEf12345`

に変更します。

## 2. GitHub Pagesで公開

1. GitHubで新しいRepositoryを作成（例: `portfolio`）
2. このフォルダ内のファイルをRepositoryへアップロード
3. GitHubの `Settings` → `Pages`
4. Sourceを `Deploy from a branch`
5. Branchを `main` / `/(root)` にしてSave
6. 数分待つと公開URLが表示されます

## 3. 作品を増やす

`works/background.html` を複製して、作品名・説明・画像を変更すると作品ページを増やせます。

## 4. 就活用に追加すると強いもの

- 完成画像
- ワイヤーフレーム
- テクスチャ / UV
- 制作期間
- 使用ソフト
- 自分が担当した範囲
- 工夫した点
- 制作途中 → 完成の比較
- YouTubeの制作動画

このテンプレートは、背景・キャラクター・アニメーションの3作品を最初から掲載できる構成です。
